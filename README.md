# missive-claude-panel

Panneau iFrame pour Missive. Il ne contient aucun secret.

- `index.html` : petite coquille qui charge le panneau depuis le serveur local (`http://localhost:4823/panel.html`) de la personne qui l'utilise. Les mises à jour se font donc sur le PC, sans republier ici.
- `full.html` : copie figée du panneau complet, en secours.
- `icon.png` : icône de l'intégration.
